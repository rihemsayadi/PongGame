# Pong Game 🌸

A simple Pong game built in Python using Pygame.

This project recreates the classic Pong game with a pink theme, singleplayer AI, local multiplayer, multiple difficulty levels, and a resizable game window.

## Features

- Singleplayer mode
- Local multiplayer mode
- Three AI difficulties:
  - Easy
  - Normal
  - Impossible
- 5-life system
- Game over and replay screens
- Resizable game window
- Responsive game layout
- Mouse hover effects
- Pink themed interface
- Heart-based life display

## Controls

### Singleplayer

- `W` - Move paddle up
- `S` - Move paddle down

### Multiplayer

**Left Paddle**
- `W` - Move up
- `S` - Move down

**Right Paddle**
- `↑` - Move up
- `↓` - Move down
